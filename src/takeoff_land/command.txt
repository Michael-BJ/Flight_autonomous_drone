========================================================================
  TAKEOFF / HOVER / LAND — Quick Start Guide
  Platform: Jetson Orin Nano | PX4 via MAVROS | ROS2 Humble
========================================================================

PREREQUISITES
-------------
- PX4 must have a valid LOCAL POSITION (GPS fix required).
- RC transmitter ON with kill-switch ready at all times.
- COM_RC_OVERRIDE=2 set in QGroundControl (enables RC takeover in OFFBOARD).
- Serial port access: sudo usermod -aG dialout $USER  (then re-login)

------------------------------------------------------------------------
STEP 1 — Source workspace  (every new terminal)
------------------------------------------------------------------------

    source /opt/ros/humble/setup.bash
    source ~/drone_ws/install/setup.bash

------------------------------------------------------------------------
STEP 2 — Build package
------------------------------------------------------------------------

    cd ~/drone_ws
    colcon build --packages-select takeoff_land
    source install/setup.bash

------------------------------------------------------------------------
STEP 3 — Launch (USB connection default)
------------------------------------------------------------------------

    ros2 launch takeoff_land takeoff_land.launch.py \
        fcu_url:=/dev/ttyACM0:57600

    # Jetson UART:
    ros2 launch takeoff_land takeoff_land.launch.py \
        fcu_url:=/dev/ttyTHS1:921600

    # With custom flight parameters:
    ros2 launch takeoff_land takeoff_land.launch.py \
        fcu_url:=/dev/ttyACM0:57600 \
        target_alt:=2        \
        hover_time:=8.0        \
        descent_speed:=0.3     \
        max_pos_error:=0.5     \
        max_vz:=1.0            \
        max_alt_error:=0.5

------------------------------------------------------------------------
PARAMETERS
------------------------------------------------------------------------

  FLIGHT
    target_alt      float  1.2   Takeoff height in meters above ground
    hover_time      float  8.0   How long (seconds) to hold hover before landing
    descent_speed   float  0.3   Descent speed in m/s during controlled landing
    land_handoff_alt float 0.25  Altitude (m) at which AUTO.LAND takes over

  SAFETY — SANITY CHECK  (auto-abort to AUTO.LAND if exceeded)
    max_pos_error   float  1.0   Max horizontal drift from home position (m)
    max_vz          float  3.0   Max vertical speed during hover / descent (m/s)
                                 Not checked during takeoff climb.
    max_alt_error   float  1.5   Max altitude deviation from target during hover (m)

  EKF / TIMING
    use_ekf_stable  bool   true  Wait for EKF Z stability before arming
                                 Pre-wait 10s, then requires std < 0.08m for 5s
    connect_timeout float  60.0  Timeout waiting for MAVROS connection (sec)
    arm_timeout     float  30.0  Timeout for ARM attempts (sec)
    cmd_hz          int    50    Setpoint publish frequency (Hz)
    auto_land_mode  bool   true  Hand final touchdown to PX4 AUTO.LAND

------------------------------------------------------------------------
FSM SEQUENCE
------------------------------------------------------------------------

  IDLE     -> Wait for MAVROS connection
           -> Wait for valid GPS / local position
           -> Pre-wait 10s for GPS/EKF convergence
           -> Check EKF Z std < 0.08m for 5s -> lock ground_z
           -> Lock home position (x, y, yaw)
           -> Warm-up setpoint stream ~2s
  ARM      -> Send ARM, confirm armed
  OFFBOARD -> Set OFFBOARD mode
  TAKEOFF  -> Rise to ground_z + target_alt
           -> Sanity: pos drift checked
  HOVER    -> Hold position for hover_time seconds
           -> Sanity: pos drift + vz + altitude deviation checked
  LANDING  -> Controlled descent at descent_speed m/s
           -> Sanity: pos drift + vz checked
           -> At land_handoff_alt -> AUTO.LAND -> disarm
  DONE     -> Landed and disarmed

------------------------------------------------------------------------
ABORT BEHAVIOUR
------------------------------------------------------------------------

  RC OVERRIDE   : RC stick movement in OFFBOARD -> setpoints stop immediately.
                  RC pilot has full control. Do NOT restart until landed.

  SANITY ABORT  : Any limit exceeded -> AUTO.LAND sent, node shuts down.
                  Example log:
                    [SANITY] ABORT: Horizontal drift 2.45m from home (limit 2.0m)
                    [SANITY] Switching to AUTO.LAND for safety.

------------------------------------------------------------------------
MONITORING  (separate terminal)
------------------------------------------------------------------------

    # FCU status (connected / armed / mode):
    ros2 topic echo /px4/state

    # Full sensor snapshot (position, GPS, IMU, battery):
    ros2 topic echo /px4/sensors

    # Setpoints being sent to PX4:
    ros2 topic echo /mavros/setpoint_raw/local

    # Real-time mode monitor with color output:
    ros2 run takeoff_land mode_monitor
